Camel Kit has a new home at the Apache Software Foundation as an official Apache Camel subproject. Its documentation now lives on camel.apache.org and its source code is developed in the Apache organisation on GitHub.

This site is no longer updated. Everything that used to be here, from getting started to the architecture and reference pages, is available at the new address.
